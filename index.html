How to use

Takes under a minute. No installation needed.

  1. Download Remove-User.bat using the button above.
  2. Right-click the file and choose Run as administrator.
  3. Choose 1 for the popup list — highlight accounts (Ctrl + click for multiple) and press OK. Choose 2 to type names manually instead.
  4. Confirm with Y. Each account (net user /delete), its profile folder and orphan registry entries are removed.
  5. Your own logged-in account is never deleted — it remains as the surviving admin.

FAQ

Common questions before you run the script.

What exactly gets deleted?

The local account (net user /delete), the C:\Users\<name> profile folder, and any orphaned profile registry entries. There is no recycle bin for this — it is unrecoverable.

A folder survived the run. Why?

A file was open or locked by another process. Restart the PC, make sure nothing of that user is running, and run the script again — or delete the folder manually.

The popup doesn't appear. What now?

The script falls back to manual typing automatically. Type names separated by spaces or commas, e.g. test1 test2, and press Enter.

Does it work on Windows 7, 8 or XP?

Yes, with automatic fallbacks. On Windows 8 / 10 / 11 everything works including the popup picker. On Windows 7 the popup needs PowerShell 3.0 or newer (present on most updated PCs) — otherwise the script falls back to manual typing, and deletion itself uses plain net user + folder delete, which work everywhere. On XP there is no popup (no PowerShell), so manual mode is used and the script also checks the old Documents and Settings profile path.
