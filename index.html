🧹 Batch Remove User Accounts (Windows)

Run the Remove-User.bat file as Administrator → it asks which user(s) to delete → deletes the account + C:\Users\<name> data.

⚠️ Warning — Data loss is permanent.
Run only as Administrator. Never delete your own logged-in account or system accounts (Administrator, Default, Public, Guest — script auto-skips these). Close all files of the target user first.

🚀 How to use

  1. Click Download above to get Remove-User.bat.
  2. Right-click the file → Run as administrator (bina admin ke delete nahi hoga).
  3. Script saare local users + C:\Users folders ki list dikhayega.
  4. Jab pooche “Kaun-kaunse user delete karne hai?” → naam likho, e.g. test1 test2 ya test1,test2.
  5. Y se confirm karo → account (net user /delete) + profile folder + orphan registry entry delete ho jayega.
  6. Khud ka logged-in account aur system accounts auto-skip hote hain.
